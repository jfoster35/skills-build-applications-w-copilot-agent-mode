# Photo Scanner (iOS) — MVP

A native iOS app that digitizes physical photo prints: hold your phone over a
photo, it auto-detects the edges, captures, enhances, and saves to your Photos
library. Fully on-device, no account, no network.

See [`docs/PhotoScanner_PRD.md`](docs/PhotoScanner_PRD.md) for the full product spec.

> **Status:** First-draft scaffold generated by Claude Code in a remote
> (Linux) session — **it has not been compiled.** The first job on your Mac is
> to generate the project, build it, and fix any first-compile issues, then walk
> the PRD build sequence on a physical device. See `CLAUDE.md`.

---

## Requirements

- **A Mac with Xcode 16+** (iOS development only works on macOS)
- **A physical iPhone (12 or newer)** — the camera + Vision framework do **not**
  work in the Simulator, so this whole app must be tested on a real device
- An Apple ID for free on-device deployment (a paid Developer account is only
  needed later for TestFlight / App Store)
- [XcodeGen](https://github.com/yonyz/XcodeGen) to generate the Xcode project
  from `project.yml`

## First-time setup on your Mac

```bash
# 1. Install XcodeGen (one time)
brew install xcodegen

# 2. Generate the Xcode project from project.yml
cd PhotoScanner
xcodegen generate

# 3. Open it
open PhotoScanner.xcodeproj
```

Then in Xcode:

1. Select the **PhotoScanner** target → **Signing & Capabilities** → choose your
   **Team** (your Apple ID). Xcode will auto-manage the bundle ID / provisioning.
2. Plug in your iPhone, select it as the run destination.
3. Press **⌘R** to build & run. Approve the developer profile on the device if
   prompted (Settings → General → VPN & Device Management).

> The `.xcodeproj` is git-ignored on purpose — it's regenerated from
> `project.yml`. When you add or rename Swift files, re-run `xcodegen generate`.

dependencies — all Apple-native. iOS 16 minimum.
